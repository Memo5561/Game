# Store-Eintrag – Texte zum Kopieren

Alles hier ist für die Play Console vorbereitet (**Wachstum → Store-Präsenz → Haupt-Store-Eintrag**,
bzw. ähnlich benannt). Die Zeichenzahlen sind geprüft. Kopiere jeweils den Inhalt der Code-Blöcke.

**Regeln, die Google streng prüft** (Metadaten-Richtlinie):

- Keine Aussagen wie „#1“, „Bestes Spiel“, „Top“, „Kostenlos“ im **Titel**, keine Emojis im Titel,
  keine durchgehende GROSSSCHREIBUNG im Titel (außer beim Markennamen)
- Keine Fremdmarken (z. B. „Tetris“ oder Namen von Konkurrenzspielen) im Titel, in Beschreibungen
  oder als Stichwortliste
- Keine irreführenden Versprechen (keine erfundenen Auszeichnungen oder Spielerzahlen, keine
  Gewinne)
- Kein Keyword-Stuffing (keine Listen von Suchbegriffen, keine Wiederholungen)
- Die Texte unten beschreiben nur Funktionen, die es im Spiel wirklich gibt. Wenn du Funktionen
  änderst, passe die Texte an.

## 5. Promo-Video (optional)

Ein YouTube-Link (öffentlich oder „nicht gelistet“, ohne Altersbeschränkung, einbettbar, ohne
Werbung im Video). Querformat ist am sichersten. Prüfe die aktuellen Vorgaben in der Console.

**Idee: 20–25 Sekunden „befriedigende Abräum-Momente“**

| Sekunde | Inhalt |
|---|---|
| 0–2 | Großes Logo „Blocko“ über einem fast vollen Spielfeld |
| 2–8 | Ein Block wird abgelegt → eine Reihe **und** eine Spalte verschwinden gleichzeitig, Partikel, „Great!“ |
| 8–14 | Kombo-Kette x2 → x3 → x4 mit steigendem Sound |
| 14–18 | Schnitt: Abenteuer-Level, Edelsteine werden gesammelt, 3 Sterne |
| 18–21 | Kurzer Wechsel durch Designs (Juwel → Neon → Holz → Gold) |
| 21–25 | Komplett leeres Spielfeld + Bonus, Endkarte „Blocko – Block Puzzle“ |

Aufnehmen: Bildschirmaufnahme am Handy oder im Browser (`npm run serve`, Handy-Ansicht der
Chrome-Entwicklertools). Mit `?debug=1` und `__blocko.startGame(...)` kannst du fertige
Spielsituationen vorbereiten. Kurze Varianten (10–15 s, Hochformat) eignen sich auch für TikTok,
Shorts und Reels (siehe [MARKETING.md](MARKETING.md)).
